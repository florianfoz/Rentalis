# Rentalis

**Open-source property management software**

Rentalis is an open-source property management application designed to simplify the management of rental properties, tenants, landlords, rents, invoices and receipts.

It is built with **C++ / Qt 6** and provides a desktop-oriented management environment with SQL data storage, document generation, printing, email assistance, tax calculation, configurable charts and AI-assisted features.

## Features

* 🏠 Property management
* 👤 Tenant management
* 👔 Landlord management
* 💰 Rent management
* 🧾 Invoice and receipt management
* 🖨️ Automatic invoice and receipt printing
* 🗄️ SQL-based data management
* 💾 Data persistence and management
* 📧 Email generation assistance
* 🤖 AI-assisted analysis and prompt generation
* 🧮 Tax calculation
* 📊 Configurable charts
* 🌍 Translation support
* 🎨 Customizable themes

## Technology

Rentalis is currently built with:

## Building

### Requirements

* CMake
* A C++ compiler supporting the required C++ standard
* Qt 6.5 or later
* Qt Quick
* Qt SQL
* Qt PDF
* Qt Charts
* Qt PrintSupport

Clone the repository:

```bash
git clone https://github.com/TheProgrammare/Rentalis.git
cd Rentalis
```

Then configure and build the project using your preferred CMake workflow.
